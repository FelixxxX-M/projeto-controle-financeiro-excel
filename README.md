# Controle Financeiro Pessoal — Excel

# Sobre o projeto

Este projeto foi desenvolvido durante meus estudos de Excel básico, com o objetivo de praticar fórmulas, funções e ferramentas de organização de dados por meio de uma planilha de controle financeiro pessoal.

A planilha permite visualizar receitas, despesas, saldo final e uma meta de gastos.

##  Objetivos

- Praticar os conhecimentos adquiridos no curso de Excel.
- Organizar informações financeiras em uma planilha.
- Desenvolver habilidades básicas de análise de dados.
- Construir meu portfólio inicial na área de dados.

## Funcionalidades

- Registro de receitas e despesas.
- Organização por data, descrição, categoria e tipo.
- Cálculo do total de movimentações, receitas, despesas e saldo.
- Definição de uma meta de gastos.
- Cálculo da diferença entre as despesas e a meta.
- Formatação de células, textos e valores monetários.
- Congelamento de linhas e colunas.

## Funções e recursos do Excel utilizados

- **Funções matemáticas:** cálculos de totais e saldo.
- **Referências relativas e absolutas:** utilização de referências em fórmulas.
- **MAIÚSCULA:** conversão de textos para letras maiúsculas.
- **MINÚSCULA:** conversão de textos para letras minúsculas.
- **CONCATENAR:** união de textos.
- **LOCALIZAR:** identificação da posição de um texto.
- **AGORA e HORA:** trabalho com data e horário.
- **Formatação de texto:** organização visual dos dados.

## Ferramentas utilizadas
